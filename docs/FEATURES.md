# Feature 规划

## 待实现功能

### Feature 1: 事件影响因子量化评分系统

**目标**: 支持更强大、复杂的算法来计算历史事件的影响因子量化分数

**现状**:
- 现有影响因子分数为简单手动评估（0-100分）
- 缺乏科学的量化模型和多维度评估

**规划方案**:
1. **多维度评分模型**
   - 政治影响权重（政权更迭、制度变革）
   - 经济影响权重（财政、贸易、产业发展）
   - 社会影响权重（人口、民生、文化变迁）
   - 军事影响权重（战争规模、领土变化）
   - 国际影响权重（外交关系、条约签订）

2. **时间衰减因子**
   - 计算事件对后续历史的长远影响
   - 使用时间窗口评估即时影响 vs 持久影响

3. **连锁反应评估**
   - 识别事件的后续连锁事件
   - 计算因果链的影响传递系数

4. **AI辅助评估**
   - 使用LLM分析历史文献，生成影响评估报告
   - 基于历史学家的研究成果进行权重校准

---

### Feature 2: 基于RAG的事件关联发现

**目标**: 使用RAG（检索增强生成）技术找寻事件之间的关联关系

**现状**:
- 事件数据独立存储，缺乏关联分析
- 无法发现跨时期、跨群体的隐性关联

**规划方案**:
1. **知识库构建**
   - 将事件详细描述向量化存储
   - 建立人物、地点、时期的多维索引
   - 集成外部历史文献资料

2. **关联类型识别**
   - 因果关联（A事件直接导致B事件）
   - 并行关联（同期发生的相互影响事件）
   - 对比关联（相似性质的事件对比）
   - 人物关联（同一人物参与的多事件）

3. **RAG检索流程**
   - 向量相似度检索相关事件
   - LLM分析关联类型和强度
   - 生成关联解释文本

4. **关联数据存储**
   - 新增事件关联表（eventIdA, eventIdB, relationType, strength, explanation）
   - 支持关联关系的查询和可视化

---

### Feature 3: 历史事件关系图谱可视化

**目标**: 使用图算法和图可视化展示事件及关联人物之间的联系，佐证历史事件不是孤立存在的

**现状**:
- 现有展示为时间轴表格形式
- 无法直观展示复杂的人物-事件网络关系

**规划方案**:
1. **图数据模型**
   - 节点类型：事件、人物、群体、地点
   - 边类型：参与、因果、关联、对抗、合作
   - 边权重：关联强度、影响程度

2. **图算法应用**
   - 关键节点发现（PageRank识别核心事件/人物）
   - 社群发现（识别历史阵营和政治集团）
   - 路径分析（事件影响的传播路径）
   - 中心性分析（核心人物识别）

3. **可视化实现**
   - 使用 D3.js 或 G6 实现交互式关系图谱
   - 支持节点点击查看详情
   - 支持按时期、群体、人物筛选
   - 支持图布局切换（力导向、层次、环形）

4. **图谱页面**
   - 新增 `/graph` 路由
   - 左侧筛选面板（时期、人物、事件类型）
   - 中央图谱展示区域
   - 右侧详情面板（点击节点展示）
