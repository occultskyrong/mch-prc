# 因果链综合分析

> 基于蒋廷黻《中国近代史大纲》的历史事件因果链建模与分析
> 方法论定义 + 书中因果链提取 + 缺失事件清单

---

## 一、为什么需要因果链

当前事件数据（`events.json`）中，每个事件是**独立存储**的，只有 `relatedEvents` 字段做简单关联。但历史事件的本质是**因果网络**：

- 为什么发生中原大战？因为军阀割据，争权夺势。
- 为什么有军阀？因为有私人武装。
- 私人武装何时开始建立？始于湘军团练。

如果数据中缺少"湘军建立"这个事件，就无法解释"军阀割据"的根源。因果链分析的目的就是**发现这些缺失的关键节点**。

## 二、三层模型

```
表层事件 ────── 具体、可时间点定位的历史事件
   │              例：中原大战、甲午海战、鸦片战争
   │
中层结构 ────── 持续存在的制度、势力、经济模式
   │              例：军阀割据、私人武装、团练制度、朝贡体系
   │
深层根源 ────── 文化、思想、经济基础、人口结构
                  例：旧社会循环套、落伍于近代文化、士大夫守旧
```

**使用规则**：分析事件时，必须同时标注它属于哪一层，以及它向上和向下连接的事件。

## 三、五种因果关系

| 类型 | 说明 | 例子 |
|------|------|------|
| **直接因果** | A 直接导致 B | 鸦片战争失败 → 南京条约 |
| **结构孕育** | 长期结构孕育事件 | 团练制度 → 湘军 → 军阀割据 |
| **错失机会** | 若不X就不会有Y | 道光不改革 → 丧失二十年 → 英法联军更惨 |
| **路径依赖** | A 的模式被后续继承 | 湘军 → 淮军 → 北洋军 → 军阀 |
| **复合原因** | A+B+C 共同导致 D | 甲午战败 = 经费挪用 + 战术落后 + 制度不彻底 |

## 四、缺失事件发现方法

1. **因果断裂检测**：A → ? → B，中间缺环节
2. **源头追溯**：从表层事件逐层向下找根源
3. **平行对比**：史料中提到但数据中不存在的事件
4. **结构补全**：多个事件共享的前提条件本身不存在

## 八、与 HPIF 算法的关系

因果链分析是对 HPIF (Historical Perspective Impact Factor) 的补充：

- **HPIF** 回答"这个事件有多重要"（量化的影响评分）
- **因果链** 回答"这个事件为什么重要"（定性的因果解释）

两者结合：一个事件的 HPIF 分数高，往往因为它是因果链中的关键节点（多层结构交汇点或路径依赖的起点）。
