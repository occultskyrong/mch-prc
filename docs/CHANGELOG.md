## v1.0.0

**发布日期**: 2026-04-17

### 核心功能

- **时间轴矩阵可视化**: 
  - 横轴时间（年份）、纵轴群体/人物
  - 支持四种视图：时间×群体、时间×人物、按群体、按人物
- **历史时期划分**: 
  - 鸦片战争时期 (1839-1860)
  - 洋务运动时期 (1861-1894)
  - 甲午战后时期 (1895-1900)
  - 清末新政时期 (1901-1911)
  - 民国初期 (1912-1926)
  - 国民政府时期 (1927-1949)
- **事件筛选**: 
  - 搜索事件标题
  - 选择年份范围
  - 筛选事件类型
  - 筛选参与群体
- **事件详情**: 
  - 抽屉显示事件详细信息
  - 包含时间、地点、概述、动机、经过、结果、影响
  - 显示参与人物及其所属群体

### 数据

- **历史事件**: 1075 条（包含93个子事件）
- **人物**: 478 人
- **群体**: 13 个

### 技术栈

- React 18 + TypeScript
- Ant Design 5
- Vite 5
- 纯静态部署（JSON数据文件）
