# 历史事件因果链分析方法论

> 本文档定义了项目中历史事件因果关系的建模方法，用于识别事件间的逻辑关联并发现缺失事件。

## 为什么需要因果链

当前事件数据（`events.json`）中，每个事件是**独立存储**的，只有 `relatedEvents` 字段做简单关联。但历史事件的本质是**因果网络**：

- 为什么发生中原大战？因为军阀割据，争权夺势。
- 为什么有军阀？因为有私人武装。
- 私人武装何时开始建立？始于湘军团练。

如果数据中缺少"湘军建立"这个事件，就无法解释"军阀割据"的根源。因果链分析的目的就是**发现这些缺失的关键节点**。

## 三层模型

```
表层事件 ────── 具体、可时间点定位的历史事件
   │              例：中原大战、甲午海战、鸦片战争
   │
中层结构 ────── 持续存在的制度、势力、经济模式
   │              例：军阀割据、私人武装、团练制度、朝贡体系
   │
深层根源 ────── 文化、思想、经济基础、人口结构
                  例：旧社会循环套、落伍于近代文化、士大夫守旧
```

**使用规则**：分析事件时，必须同时标注它属于哪一层，以及它向上和向下连接的事件。

## 五种因果关系

| 类型 | 说明 | 例子 |
|------|------|------|
| **直接因果** | A 直接导致 B | 鸦片战争失败 → 南京条约 |
| **结构孕育** | 长期结构孕育事件 | 团练制度 → 湘军 → 军阀割据 |
| **错失机会** | 若不X就不会有Y | 道光不改革 → 丧失二十年 → 英法联军更惨 |
| **路径依赖** | A 的模式被后续继承 | 湘军 → 淮军 → 北洋军 → 军阀 |
| **复合原因** | A+B+C 共同导致 D | 甲午战败 = 经费挪用 + 战术落后 + 制度不彻底 |

## 缺失事件发现方法

1. **因果断裂检测**：A → ? → B，中间缺环节
2. **源头追溯**：从表层事件逐层向下找根源
3. **平行对比**：史料中提到但数据中不存在的事件
4. **结构补全**：多个事件共享的前提条件本身不存在

## 事件数据扩展方案

### 在 events.json 中增加因果链字段

```typescript
interface CausalLink {
  eventId: number;        // 关联事件的 ID
  relation: 'causes'      // 本事件导致了关联事件
           | 'caused_by'  // 本事件被关联事件导致
           | 'enables'    // 本事件的结构使关联事件成为可能
           | 'enabled_by' // 本事件被关联事件的结构所孕育
           | 'missed_opportunity'; // 若本事件做了不同选择可避免关联事件
}

interface Event {
  // ... 现有字段 ...
  causalChain?: {
    layer: 'surface' | 'structural' | 'root';  // 三层模型中的层级
    causes: CausalLink[];       // 导致的后续事件
    causedBy: CausalLink[];     // 的前置原因
  };
}
```

### 缺失事件提案格式

当发现缺失事件时，按以下格式提案：

```markdown
## 缺失事件: [事件名称]

**在因果链中的位置**: [深层根源/中层结构/表层事件] A → [本事件] B → C

**缺失类型**: [因果断裂 / 源头追溯 / 平行对比 / 结构补全]

**史料依据**: [引用具体史料来源和内容]

**建议的 event 结构**:
{
  title: "...",
  startDate: "...",
  eventType: "...",
  detail: { motive: "...", process: "...", result: "...", impact: "..." },
  causalChain: {
    layer: "...",
    causes: [{ eventId: X, relation: "causes" }],
    causedBy: [{ eventId: Y, relation: "caused_by" }]
  }
}
```

## 实际应用案例

### 案例：军阀割据的因果溯源

```
[深层根源] 旧社会循环套
  (人口压力 → 吏治腐败 → 民不聊生 → 民间武力)
    │
    ▼ 结构孕育
[中层结构] 团练制度（缺失事件）
  (民间自卫武力，曾国藩组织化)
    │
    ▼ 直接因果
[中层结构] 湘军建立（缺失事件）
  (精神教育 + 宗族乡土 + 厚饷，但私有化)
    │
    ▼ 路径依赖
[中层结构] 淮军继承（缺失事件）
  (李鸿章继承湘军模式)
    │
    ▼ 路径依赖
[中层结构] 北洋军阀（缺失事件）
  (袁世凯继承并扩张)
    │
    ▼ 结构孕育
[表层事件] 军阀割据 / 中原大战
  (现有事件，但缺少上游因果解释)
```

### 案例：鸦片战争的深层因果

```
[深层根源] 中西文化根本差异
  (东方朝贡体系 vs 西方平等邦交)
    │
    ▼ 结构孕育
[中层结构] 一口通商制度 + 朝贡外交观念
    │
    ▼ 直接因果
[表层事件] 马戛尔尼使团失败 (1793)
    │
    ▼ 错失机会
和平交涉路径被堵死
    │
    ▼ 路径依赖
英国转向鸦片贸易 → 禁烟冲突 → 鸦片战争
```

## 与现有 HPIF 算法的关系

因果链分析是对 HPIF (Historical Perspective Impact Factor) 的补充：

- **HPIF** 回答"这个事件有多重要"（量化的影响评分）
- **因果链** 回答"这个事件为什么重要"（定性的因果解释）

两者结合：一个事件的 HPIF 分数高，往往因为它是因果链中的关键节点（多层结构交汇点或路径依赖的起点）。
