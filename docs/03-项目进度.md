## 附录

### A. 数据采集规范

**来源优先级**：官方史料 > 学术著作 > 百科资料 > 其他资料

**采集原则**：
- 史料真实性：多来源交叉验证，标注来源等级
- 中华人民共和国视角：以马克思主义历史观为指导
- 完整性：事件需包含时间、地点、人物、经过、结果、影响

**采集流程**：
1. 确定采集目标（按年份顺序，先重大后细节）
2. 多来源验证（维基百科、百度百科、历史著作）
3. 原始数据存入 raw/ 对应年份目录
4. 数据清洗：去冗余、统一日期格式、关联人物群体ID

**年份采集顺序**：

| 阶段 | 年份范围 | 重点事件 |
|------|----------|----------|
| 第一阶段 | 1840-1842 | 鸦片战争 |
| 第二阶段 | 1851-1864 | 太平天国运动 |
| 第三阶段 | 1861-1895 | 洋务运动 |
| 第四阶段 | 1894-1895 | 甲午战争 |
| 第五阶段 | 1898 | 戊戌变法 |
| 第六阶段 | 1911-1912 | 辛亥革命 |
| 第七阶段 | 1919 | 五四运动 |
| 第八阶段 | 1921-1949 | 中共党史 |

**人物收录标准**：直接参与重大历史事件、对历史进程有显著影响、在史料中有明确记载

**群体收录标准**：有明确的政治立场或社会诉求、对历史进程有集体性影响、有代表性人物可追溯

**来源标注格式**：
```json
{
  "sourceId": 1,
  "sourceType": "book",
  "sourceName": "《中国近代史》",
  "author": "蒋廷黻",
  "publishYear": 1938
}
```

### C. 历史事件参考

**鸦片战争时期（1839-1860）**
- 1840年：英国出兵、议会通过、攻占定海、大沽口谈判、林则徐革职
- 1841年：虎门之战、三元里抗英、英占香港
- 1842年：吴淞之战、镇江之战、南京条约
- 1851-1864：太平天国运动（金田起义、永安建制、定都天京、北伐西征、天京事变）

**洋务运动时期（1861-1894）**
- 总理衙门设立、江南制造总局、福州船政局、轮船招商局
- 幼童留美、中法战争（马尾海战、镇南关之战）

**甲午战后时期（1895-1900）**
- 马关条约、威海卫之战、台湾抗日
- 戊戌变法、义和团与八国联军

**清末新政时期（1901-1911）**
- 辛丑条约、清末新政、废除科举、五大臣出洋、预备立宪
- 徐锡麟起义、辛亥革命

**民国初期（1912-1927）**
- 清帝退位、宋教仁案、二次革命、护国运动
- 五四运动、中共成立、北伐战争

**国民政府时期（1927-1949）**
- 中原大战、长征、遵义会议、西安事变
- 抗日战争：淞沪会战、太原会战、台儿庄战役、武汉会战、百团大战
- 解放战争：辽沈战役、淮海战役、平津战役、渡江战役
