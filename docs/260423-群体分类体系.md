# 群体分类体系：9 阵营 + 二级子群体

## 概述

人物/组织按政治效忠、历史身份归属到 9 个一级阵营，每个阵营下设若干二级子群体，共 33 个子群体。

## 阵营划分规则

### 规则 1：按政治效忠
人物效忠于哪个政权/组织，就归哪个阵营。
- 清朝官员、将领 → 清廷
- 北洋政府官员/军阀 → 军阀
- 国民政府官员 → 国民党

### 规则 2：按主要身份
跨时期人物按其最主要历史身份归类。
- 袁世凯：清末重臣但核心身份是北洋军阀 → 军阀
- 张学良：奉系出身但核心历史事件（东北易帜、西安事变）在国民党时期 → 国民党

### 规则 3：按组织归属
属于某组织的成员、军队、机构，归该组织。
- 国民革命军 → 国民党
- 红军/八路军/解放军 → 中国共产党

### 规则 4：外国势力按国别
外国人/外国机构按所属国家归入对应阵营。
- 英国 → 外国势力
- 日本 → 日本侵略军（独立阵营）

### 规则 5：模糊概念按事件语境
无明确组织归属的，按其首次出现事件的时代背景归类。
- 1872 留美幼童 → 清廷
- 1919 中国代表团 → 军阀

### 规则 6：叛变者特殊处理
人物后期叛变投靠敌方的，不归入投靠方的正面阵营。
- 汪精卫：早期国民党核心，后期投日成立伪政府 → 其他-汉奸
- 不归日本侵略军（那是正面敌方），也不归国民党（已叛变）

## 子群体划分规则

### 规则 A：按职能分工
同一阵营内按角色类型分。
- 清廷：皇室/官员/军队/团练/维新派
- 国民党：政党/军队/嫡系/归顺

### 规则 B：按历史阶段
跨时期的按时间阶段分。
- 日本侵略军：甲午/侵华
- 中共：早期/领导/军队

### 规则 C：按地域/派系
同阵营内不同派系。
- 军阀：北洋/直系/皖系/奉系/地方
- 外国势力：英国/法国/俄国/美国/欧洲

## 特殊处理说明

### 合并规则
- 英军、法军、美国、苏联、德国 → 外国势力（按国别分子群体）
- 维新派、湘淮系 → 清廷（按职能分子群体）
- 东北军、西北军 → 国民党（1928年后归顺）
- 日本侵略军独立为一级阵营（不并入外国势力）

### 时间归属原则
对于语义上模糊的概念（如"中国政府"、"中国代表团"），按其出现的具体历史时期判断归属，而非按字面理解。
