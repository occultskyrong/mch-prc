# 蒋廷黻《中国近代史》因果链提取

从蒋廷黻原著中可提取的主要因果链。

## 因果链 1: 鸦片战争的深层逻辑

```
[深层根源] 中西文明根本差异
  (东方朝贡体系 vs 西方平等邦交)
    │
    ▼ 结构孕育
[中层结构] 一口通商制度 + "剿夷/抚夷"外交观
    │
    ▼ 直接因果
[表层事件] 马戛尔尼使团失败 (1793)
  (跪拜礼冲突，所有通商要求被拒)
    │
    ▼ 直接因果
[表层事件] 第二次英国使节失败 (1816)
  (嘉庆待遇远不及乾隆)
    │
    ▼ 路径依赖
英国认识到"和平交涉的路走不通"
    │
    ▼ 结构孕育
[中层结构] 英国转向鸦片贸易
  (东印度公司在印度奖励种植，统制运销)
    │
    ▼ 直接因果 + 复合原因
[表层事件] 鸦片战争 (1840-1842)
  (鸦片问题: 我方禁绝 vs 英方维持 +
   通商问题: 英方求自由 vs 我方守旧制 +
   世界大势: 工业革命后英国需海外市场)
    │
    ▼ 直接因果
[表层事件] 南京条约签订 (1842)
    │
    ▼ 错失机会
[错失机会] 道光咸丰年间不改革
  (守旧性重、士大夫饭碗动摇、缺乏独立精神)
    │
    ▼ 错失机会
"中华民族丧失了二十年的宝贵光阴"
    │
    ▼ 直接因果
[表层事件] 英法联军 (1856-1860)
```

## 因果链 2: 私人武装 → 军阀割据

```
[深层根源] 旧社会循环套
  (康熙→嘉庆: 人口暴增 → 耕地不足 → 民生困苦 → 匪患)
    │
    ▼ 结构孕育
[中层结构] 社会匪患遍地
  (白莲教、回教、苗徭、海盗、会匪)
    │
    ▼ 直接因果
[中层结构] 民间团练自卫
  (务正业农民抵抗不务正业的游民土匪)
    │
    ▼ 直接因果
[表层事件] 湘军建立 (1853) ← 缺失事件
  (曾国藩组织训练团练为湘军)
  特点: 精神教育 + 宗族乡土 + 厚饷 + 水师
    │
    ▼ 路径依赖 (副作用)
[中层结构] 湘军私有化 ← 缺失事件
  (兵士只知道有直接上级长官，不知道有国家)
    │
    ▼ 路径依赖
[中层结构] 淮军继承 ← 缺失事件
  (李鸿章继承湘军模式)
    │
    ▼ 路径依赖
[中层结构] 北洋军阀 ← 缺失事件
  (袁世凯继承并扩张)
    │
    ▼ 结构孕育
[表层事件] 军阀割据 / 中原大战
  (现有事件，但缺少上游因果解释)
```

## 因果链 3: 自强运动 → 甲午战败

```
[深层根源] 英法联军教训
  (西洋军器练兵方法远在之上 + 西洋人守信义)
    │
    ▼ 直接因果
[中层结构] 自强运动 (1862-1894)
  (恭亲王+文祥+曾国藩+李鸿章+左宗棠)
  内容: 军器→人才→交通→经济，步步深入
    │
    ▼ 复合原因 (失败原因)
┌─ 领袖不彻底: 旧社会旧教育，不懂科学机械
│   觉得政治制度至善至美，无须学西洋
│
├─ 制度阻碍: 中古式财政，各省协济困难
│   皇室用钱公私不分，海军经费被挪用修颐和园
│
├─ 人才问题: 丁汝昌陆军出身管海军
│   误辞英国教官改聘德国骑兵教官
│
└─ 社会阻力: 修铁路=破坏风水
    同文馆科学班遭倭仁反对，士大夫不投考
    │
    ▼ 结构孕育
[中层结构] 东洋（日本）同时期全面维新 ← 对比
  (不但学机械，还学政治制度 + 民族精神)
    │
    ▼ 直接因果
[表层事件] 甲午战争 (1894)
  (直接起因: 朝鲜东学党起义)
    │
    ▼ 直接因果
[表层事件] 马关条约 (1895)
```

## 因果链 4: 马关条约 → 瓜分狂潮 → 辛亥革命

```
[表层事件] 甲午战败 → 马关条约 (1895)
    │
    ▼ 直接因果
[表层事件] 三国干涉还辽
  (俄国主导，德法附和)
    │
    ▼ 路径依赖
┌─ 俄国: 要修中东铁路 + 得不冻港 → 占旅顺大连
│   外交最阴险，"以助我之名行侵我之实"
│
├─ 德国: 曹州教案 → 占胶州湾 → 山东势力范围
│
├─ 英国: 要求威海卫 + 长江流域优越权利
│
├─ 法国: 要求广州湾 + 两广云南优越权利
│
└─ 日本: 要求福建为其势力范围
    │
    ▼ 结构孕育
[表层事件] 列强瓜分中国狂潮 (1897-1898)
    │
    ▼ 复合原因
┌─ 瓜分刺激 → 戊戌变法 (1898) → 失败
│   (守旧势力总动员: 废八股打破饭碗 + 裁衙门)
│
├─ 变法失败 + 外人偏袒光绪 → 顽固党恨洋人
│
└─ 民间积愤 → 义和团"扶清灭洋"
    │
    ▼ 直接因果
[表层事件] 八国联军 (1900) → 辛丑条约
    │
    ▼ 直接因果
[中层结构] 清廷信用彻底破产
    │
    ▼ 结构孕育
[表层事件] 辛亥革命 (1911)
  (直接导火线: 铁路国有计划)
```
