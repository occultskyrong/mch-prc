# 数据采集规则

本文档记录中国近代史编年体纪要系统数据采集的规范与流程。

## 数据来源优先级

按权威性排序：

1. **官方史料** - 国家档案、官方出版物
2. **学术著作** - 高校教材、学术论文
3. **百科资料** - 维基百科、百度百科
4. **其他资料** - 历史爱好者整理资料

## 采集原则

### 史料真实性

- 优先选择有明确出处的史料
- 多来源交叉验证关键事实
- 标注史料来源等级

### 中华人民共和国视角

- 以马克思主义历史观为指导
- 突出人民群众的历史作用
- 强调中国共产党在革命中的领导地位

### 完整性要求

- 事件需包含：时间、地点、人物、经过、结果、影响
- 人物需包含：生卒年、身份、主要活动、所属群体
- 群体需包含：名称、性质、主要人物、历史作用

## 采集流程

### 1. 确定采集目标

- 按年份顺序采集
- 先采集中等重大事件，再补充细节事件
- 重大事件优先：战争、条约、革命、运动

### 2. 多来源验证

每个事件至少采集 2-3 个来源：

- 维基百科（中文/英文）
- 百度百科
- 相关历史著作

### 3. 数据记录格式

原始数据存入对应年份目录，格式如下：

```markdown
## 事件名称

**时间**: YYYY-MM-DD ~ YYYY-MM-DD（或瞬间事件）

**地点**: 具体地点

**参与人物**: 人物1、人物2、...

**来源**: 
- 来源1: URL或书名
- 来源2: URL或书名

### 事件概述

简要概述事件背景、经过、结果。

### 详细内容

**动机原因**: ...

**经过描述**: ...

**结果**: ...

**影响**: ...
```

### 4. 数据清洗

将原始数据转换为结构化 JSON：

- 去除冗余内容
- 统一日期格式
- 关联人物和群体 ID
- 标注史料来源 ID

## 年份采集顺序

按历史重要性分阶段：

| 阶段 | 年份范围 | 重点事件 |
|------|----------|----------|
| 第一阶段 | 1840-1842 | 鸦片战争 |
| 第二阶段 | 1851-1864 | 太平天国运动 |
| 第三阶段 | 1861-1895 | 洋务运动 |
| 第四阶段 | 1894-1895 | 甲午战争 |
| 第五阶段 | 1898 | 戊戌变法 |
| 第六阶段 | 1911-1912 | 辛亥革命 |
| 第七阶段 | 1919 | 五四运动 |
| 第八阶段 | 1921-1949 | 中共党史 |

## 人物采集规则

### 人物分类

- **政治人物**: 皇帝、官员、革命家
- **军事人物**: 将领、指挥官
- **思想人物**: 学者、思想家
- **社会人物**: 商人、民间领袖

### 人物收录标准

- 直接参与重大历史事件
- 对历史进程有显著影响
- 在史料中有明确记载

## 群体采集规则

### 群体类型

- **政治派别**: 洋务派、维新派、革命派
- **社会组织**: 同盟会、中国共产党
- **社会阶层**: 农民阶级、工人阶级
- **学术流派**: 各种思想流派

### 群体收录标准

- 有明确的政治立场或社会诉求
- 对历史进程有集体性影响
- 有代表性人物可追溯

## 来源标注规范

每条数据需标注来源：

```json
{
  "sourceId": 1,
  "sourceType": "book",
  "sourceName": "《中国近代史》",
  "author": "蒋廷黻",
  "publishYear": 1938
}
```

来源类型：

- `book` - 书籍
- `archive` - 档案
- `website` - 网站
- `paper` - 学术论文
