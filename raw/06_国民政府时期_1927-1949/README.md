# 国民政府时期 (1927-1949)

> 从南京国民政府成立到中华人民共和国建立，十年内战、抗日战争、解放战争。

## 时期概述

这一时期是中国现代史的关键时期：
- **1928年**: 北伐完成，形式上统一
- **1930年**: 中原大战，蒋介石击败反蒋联军
- **1934年**: 第五次反围剿失败，长征开始
- **1935年**: 遵义会议确立毛泽东领导，华北事变
- **1936年**: 西安事变，国共合作抗日
- **1937年**: 七七事变，全面抗战开始
- **1945年**: 抗战胜利
- **1947年**: 孟良崮战役，刘邓大军挺进大别山
- **1949年**: 中华人民共和国成立
