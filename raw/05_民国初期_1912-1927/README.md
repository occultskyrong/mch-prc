# 民国初期 (1912-1927)

> 从清帝退位到北伐成功，民国建立但军阀混战，五四运动开启新文化时代。

## 时期概述

这一时期民国初建但动荡不安：
- **1912年**: 清帝退位，民国成立，袁世凯就任临时大总统
- **1913年**: 宋教仁被杀，二次革命失败
- **1915年**: 二十一条，袁世凯称帝
- **1916年**: 护国运动，袁世凯去世
- **1919年**: 五四运动
- **1921年**: 中国共产党成立
- **1924年**: 国共合作，黄埔军校成立
- **1926年**: 北伐战争开始
- **1927年**: 北伐成功，南京国民政府成立，四一二事件
