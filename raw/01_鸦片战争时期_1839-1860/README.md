# 鸦片战争时期 (1839-1860)

> 从林则徐禁烟到第二次鸦片战争结束，中国被迫打开国门，开始沦为半殖民地。

## 时期概述

这一时期是中国近代史的开端：
- **1839年**: 林则徐虎门销烟，九龙之战
- **1840年**: 鸦片战争爆发，英军攻占定海，林则徐被革职
- **1841年**: 虎门之战关天培战死，英军占领香港，三元里抗英
- **1842年**: 南京条约签订，中国割让香港、赔款2100万银元
- **1851年**: 金田起义，太平天国建立
- **1856年**: 第二次鸦片战争爆发
- **1860年**: 英法联军攻占北京，火烧圆明园，签订北京条约
