# 清末新政时期 (1901-1911)

> 从辛丑条约到辛亥革命，清政府推行改革但未能挽救统治，武昌起义成功。

## 时期概述

这一时期清政府推行新政改革：
- **1901年**: 辛丑条约签订，清末新政开始
- **1903年**: 商部设立，苏报案发生
- **1905年**: 废除科举，五大臣出洋考察宪政
- **1906年**: 预备立宪，官制改革
- **1907年**: 徐锡麟起义，秋瑾就义，东三省改制
- **1908年**: 光绪慈禧相继去世
- **1911年**: 武昌起义，辛亥革命爆发

## 关键事件

| 事件 | 时间 | 概述 |
|------|------|------|
| 废除科举 | 1905年 | 延续千年的科举制度终结 |
| 预备立宪 | 1906年 | 清政府宣布准备实行宪政 |
| 徐锡麟起义与秋瑾就义 | 1907年7月 | 革命党人起义失败 |
| 辛亥革命 | 1911年9月-11月 | 武昌起义，各省独立 |
