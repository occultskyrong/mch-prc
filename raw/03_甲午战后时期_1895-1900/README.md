# 甲午战后时期 (1895-1900)

> 从马关条约到义和团运动，中国危机加深，戊戌变法失败，庚子国变惨重损失。

## 时期概述

这一时期中国面临严重危机：
- **1895年**: 马关条约签订，割让台湾，洋务运动失败
- **1898年**: 戊戌变法推行百日维新，政变后六君子被杀
- **1900年**: 义和团运动，八国联军侵华，辛丑条约赔款4.5亿两
