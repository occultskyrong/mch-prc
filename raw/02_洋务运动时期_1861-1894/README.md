# 洋务运动时期 (1861-1894)

> 从总理衙门设立到甲午战争爆发，洋务派推动"自强求富"，但甲午战败宣告失败。

## 时期概述

这一时期洋务派推行改革：
- **1861年**: 总理衙门设立，辛酉政变，洋务运动开始
- **1862年**: 京师同文馆成立，李鸿章组建淮军
- **1865年**: 江南制造总局创办
- **1866年**: 福州船政局创办
- **1872年**: 轮船招商局创办，幼童留美
- **1883年**: 中法战争开始
- **1885年**: 台湾建省
- **1894年**: 甲午战争爆发，黄海海战邓世昌殉国
